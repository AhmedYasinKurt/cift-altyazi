# Çift Altyazı

Android tablette (Firefox + Violentmonkey) YouTube izlerken:

- İngilizce (orijinal) altyazıyı açıp kapatma,
- Türkçe çeviriyi **sürekli** ya da **TR tuşuyla gerektiğinde** (video durur, Türkçe çıkar) gösterme.

Kurulum ve kullanım için: [KULLANIM.md](KULLANIM.md)

Geliştirici notları: [tasarım](docs/superpowers/specs/2026-11-23-cift-altyazi-design.md), [plan](docs/superpowers/plans/2026-11-23-cift-altyazi.md). Testler: `npm test`.
